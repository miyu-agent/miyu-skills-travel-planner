# Travel planner

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a skill package for Miyu. It provides one skill, `travel-planner`, and two tools, `flight_deals` and `hotel_deals`. Following the skill, the AI plans itineraries and works out budgets, citing a source for its information; flight and hotel prices are looked up with the two tools.

## The `flight_deals` tool: flight price comparison

Google Flights encodes the route, dates, cabin class and number of travellers in the `tfs` parameter (a base64url-encoded protobuf). The script builds this parameter itself, so each lookup sends a single HTTP request and needs no browser.

| Parameter | Description |
|---|---|
| `action` | The operation to perform: `search` (the default) looks up one day; `sweep` scans a range of dates for the cheapest day; `trend` shows the price history (without a route, it lists the routes on record); `airports` looks up airport codes; `doctor` runs a self-check. |
| `origin`, `dest` | The origin and destination, as a city, an English name or a three-letter code; a city includes all of its airports (for example, Shanghai = PVG + SHA). The tool does not guess, so both are required. |
| `depart` | The departure date, written as `+30`, `10-01` or `2026-10-01`. The default is `+14`. |
| `return` | The return date. If you give it, the tool looks up the return flight as well and puts the combined price at the top. |
| `window`, `days` | For `sweep` only: the range of dates you can travel (`09-29..10-08`) and the length of the trip in days (`5` or `5-7`). If you give `days`, the tool scans the return flight as well and lists the combinations. |
| `seat` | The cabin class: `economy` (the default), `premium`, `business` or `first`. With `search`, you can pass an array or `all` to compare several classes. |
| `adults`, `children` | The number of adults and children. The defaults are 1 and 0. |
| `max_stops` | The maximum number of stops; `0` shows nonstop flights only. |
| `airline`, `depart_time`, `sort`, `top` | In order: filter by airline, filter by departure time window (`08:00-18:00`), set the sort order, and set the number of results shown. |
| `currency`, `format`, `no_record` | In order: the currency (the default is CNY), the output format (`md`/`json`), and not recording the price history. |

## The `hotel_deals` tool: hotel price comparison

Google Hotels encodes the dates and currency in the `ts` parameter, which the script also builds itself. The starting price Google shows is already the lowest price among the online travel agencies (OTAs).

| Parameter | Description |
|---|---|
| `action` | The operation to perform: `search` (the default) looks up one stay; `sweep` scans the coming days for the cheapest check-in date; `trend` shows the price history; `places` lists the places on record; `doctor` runs a self-check. |
| `location` | The place name, preferably in English (`Shinjuku, Tokyo`): Chinese names can only be matched loosely and may land more than 30 km away, and the output warns you when that happens. |
| `checkin`, `checkout`, `nights` | The check-in date, the check-out date and the number of nights. By default the stay starts 7 days from now and lasts 1 night. |
| `days` | For `sweep` only: the number of days to scan. The default is 30 and the maximum is 90. |
| `sources` | The data sources. The default is `["google"]`; add `booking` to cross-check. With `trend`, giving a source shows only that source, and leaving it out does not separate the sources. |
| `adults`, `rooms` | Only used by Booking: the number of adults and rooms. The defaults are 2 and 1. |
| `currency`, `top`, `format`, `no_record` | The same as the parameters with the same names in `flight_deals`. |

## Dependencies

The tools need the following:

- The tools use only the Python standard library, and network access to `google.com` is all they need.
- **The Booking source is optional**: to use it, first run `pip install --user playwright`, then install a browser (the system's Chrome, Edge or Chromium, or run `python3 -m playwright install chromium`). The browser runs headless, each lookup takes 10–20 seconds, and several lookups in a row get rate-limited. The `doctor` action of `hotel_deals` tells you whether the installation succeeded.
- Miyu's sandbox replaces `~/.config/chromium` with an empty read-only folder, so `hotel_deals` gives the browser its own `XDG_CONFIG_HOME` and `XDG_CACHE_HOME`, pointing to `browser-home/` under the cache folder `MIYU_CACHE_DIR`; when there is no cache folder, it uses a temporary folder and deletes it afterwards. This has not been tested inside Miyu's sandbox yet.

## Notes

Keep the following in mind when you use the tools:

- The prices are starting prices, and the price when you book may be higher; a round-trip total is the sum of two one-way tickets, not the price of a round-trip ticket.
- The price history is stored in `MIYU_STATE_DIR` (when the core does not provide this folder yet, it is kept in `MIYU_CACHE_DIR` and cleared on restart).
- The country your traffic exits from affects Google's results; `gl` is fixed to `us` for flights and `jp` for hotels, and other regions have not been tested.
